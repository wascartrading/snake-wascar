# SNAKE · La Culebrita

**Creado por Wáscar · construido por JARVIS · 2026**

La culebrita clásica, pulida y jugable desde el teléfono.

## Cómo jugar

Entra en `index.html` (o en el enlace publicado) y pulsa **Jugar ahora**.

- **Teclado:** flechas o `W` `A` `S` `D` para moverse · `Espacio` pausa · `Enter` empezar · `R` partida nueva · `M` sonido.
- **Teléfono:** desliza el dedo sobre el tablero para girar, toca el tablero para pausar, o usa la cruceta de abajo.

## Qué lleva dentro

- Tablero 24x24, velocidad progresiva (un nivel cada 5 frutas).
- Récord y partidas guardados en el navegador.
- Sonido generado al vuelo (sin archivos de audio).
- Sin librerías ni dependencias: tres archivos y listo.
- Interfaz adaptada a teléfono, tableta y PC (incluido el modo apaisado).
